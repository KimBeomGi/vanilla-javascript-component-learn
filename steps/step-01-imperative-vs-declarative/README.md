# Step 01: 명령형(Imperative) vs 선언적(Declarative) 상태 기반 렌더링

## 🎯 학습 미션
- `exercise/` 디렉토리로 이동하여 `// TODO:` 주석으로 비어있는 코드를 작성해 봅니다.
- 막히거나 정답이 궁금할 때는 `solution/` 디렉토리의 완성본 코드를 확인하세요!

---

## 📂 디렉토리 구조
- `exercise/` : 직접 퀴즈와 미션을 작성해 보는 **실습용 공간 (Starter)**
  - `imperative.html`: DOM 요소 조작 코드 미션
  - `declarative.html`: state & render() 작성 미션
- `solution/` : "짜잔~" 하고 완성되어 있는 **정답 참고용 공간 (Answer/Solution)**
  - `imperative.html`
  - `declarative.html`
